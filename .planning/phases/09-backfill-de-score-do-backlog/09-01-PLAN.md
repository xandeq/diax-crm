    1. `def capture_snapshot(api_base, token, label):` → dict. Faz `GET {api_base}/api/v1/sales-dashboard`

       `GET {api_base}/api/v1/leads` com `params={"segment": seg, "page": 1, "pageSize": 10}` (timeout=60).
       Devolve exatamente este dict:
       ```python
       {
         "label": label,
         "capturedAt": datetime.now(timezone.utc).isoformat(),
         "funnel": dash["funnel"],
         "hotLeads": dash["hotLeads"],
         "warmLeads": dash["warmLeads"],
       ```

       re-disparar cegamente: rode --snapshot-only e compare antes de decidir." — e NÃO faz retry
       automático (Pitfall 4). Em erro HTTP devolve `{"ok": False, "status": r.status_code, "body": r.text[:300]}`.

       `("hotLeads","warmLeads","coldLeads","openLeadsTotal","unsegmentedOpenLeads")` entre dois snapshots

    4. `def write_json(path, obj):` → cria `path.parent` com `mkdir(parents=True, exist_ok=True)` e grava
       com `json.dump(obj, f, ensure_ascii=False, indent=2)`, encoding utf-8. Imprime `[out] {path}`.

       - `--idempotency` : só válido junto de `--run`. Dispara um SEGUNDO recompute e captura
         `{out}/backfill_after_rerun.json`; imprime `compare(after, after_rerun)`; se a lista NÃO for
